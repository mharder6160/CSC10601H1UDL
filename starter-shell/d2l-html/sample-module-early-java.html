Sample Module: Java Foundations

  • Topics: Program structure, variables, data types, input/output
  • Estimated Time: 6-8 hours

Overview

This module introduces core Java building blocks. Students write simple programs that take input, perform calculations, and print formatted output.

Learning Outcomes

  1. Identify required structure of a Java class with main.
  2. Use appropriate primitive data types and variables.
  3. Accept keyboard input and produce clear output.
  4. Trace simple expressions and explain results.

Mini-Lesson Code Example

Code sample: IntroIO.java

import java.util.Scanner;

public class IntroIO {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = input.nextLine();

        System.out.print("Enter your age: ");
        int age = input.nextInt();

        System.out.println("Welcome, " + name + ". Next year you will be " + (age + 1) + ".");

        input.close();
    }
}

Worked Example

Task: Read student name and two quiz scores, then print average.

Pseudocode

  1. Start program
  2. Ask for first name
  3. Ask for quiz1 and quiz2
  4. Compute average as (quiz1 + quiz2) / 2.0
  5. Print name and average
  6. End program

Java Solution

Code sample: QuizAverage.java

import java.util.Scanner;

public class QuizAverage {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("First name: ");
        String firstName = in.nextLine();

        System.out.print("Quiz 1 score: ");
        double quiz1 = in.nextDouble();

        System.out.print("Quiz 2 score: ");
        double quiz2 = in.nextDouble();

        double average = (quiz1 + quiz2) / 2.0;

        System.out.printf("%s, your average is %.2f%n", firstName, average);

        in.close();
    }
}
