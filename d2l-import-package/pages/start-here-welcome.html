Welcome message for students

Welcome to Computer Science I! In this course, you will learn how to design algorithms and write Java programs that solve real problems. You do not need to be an expert before you start. You will build skill week by week through short lessons, guided practice, and programming projects.

Our class is designed so you always know:

  • what to do first,
  • how long work may take,
  • what “successful” work looks like,
  • and where to get help quickly.

How to navigate this course

Use the Content area in this order each week:

  1. Overview & Outcomes
  2. Mini-Lesson + Worked Example
  3. Guided Practice
  4. Knowledge Check
  5. Assignment / Programming Project
  6. Reflection & Next Steps

Learning support and success guidance

If you are stuck, use this sequence:

  1. Re-read the worked example
  2. Compare your output against expected output
  3. Run one test input at a time
  4. Ask a focused question in class/discussion/email
  5. Visit tutoring/support services [INSTRUCTOR CONFIRM]
