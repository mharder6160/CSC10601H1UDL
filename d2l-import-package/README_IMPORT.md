# README_IMPORT: D2L UDL Starter-Shell Test Import Package

This ZIP package is a **new UDL starter-shell test/import package** created from repository starter-shell materials. It is **not** the original Brightspace export file (`D2LExport_662798_S_PPCC_CSC10601H1_202720_20269657.zip`).

## Brightspace import steps (exact workflow)

1. Open the target Brightspace course shell.
2. Go to **Course Admin**.
3. Select **Import/Export/Copy Components**.
4. Choose **Import Components**.
5. Choose **Start**.
6. Upload `D2L_UDL_StarterShell_CSC1060.zip`.
7. Continue through the import prompts and confirm completion.

## What content this package creates

The package creates importable content-topic pages for:

- Start Here: welcome, navigation guidance, technology/Java setup guidance, communication expectations, first-week checklist
- UDL Course Design: blueprint and accessibility/quality checklist
- Weekly Module Template resource
- Sample Module 1 resource (early Java lesson, worked examples, pseudocode, guided practice, knowledge check, assignment, testing guidance, rubric)
- Assessment and Feedback Guidance
- Suggested Course Map

## Instructor confirmation required

After import, instructors should confirm and update all `[INSTRUCTOR CONFIRM]` placeholders and validate:

- course-specific policies, office hours, response timelines
- due dates and gradebook alignment
- links to local course tools/content files

## Recommended safe workflow

Import this package into a **blank shell first**, inspect all pages, then copy/adjust content into the production shell as needed.

## Limitations

This package is intended for **test/import of starter content** from static repository files. It does not claim native, fully configured Brightspace behavior in your institution instance.

Unless explicitly represented in this package, importing does **not** automatically create or configure:

- gradebook items and category calculations
- quizzes/question banks
- rubric objects
- release conditions
- tool/deep links and external integrations
- course settings and enrollment configuration
