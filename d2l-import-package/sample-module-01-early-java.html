Overview

This module introduces the structure of a Java program and core building blocks such as variables, data types, and console input and output. Students write and test simple programs that read user input, perform calculations, and print formatted results.

Learning outcomes

  1. Identify the required structure of a basic Java class with a main method.
  2. Declare and initialize variables using appropriate primitive data types.
  3. Accept keyboard input and produce clear output.
  4. Trace simple expressions and explain resulting values.

Vocabulary

  • Class: A blueprint for creating objects and a container for methods in introductory programs.
  • Method: A block of code that performs a task.
  • Main method: The entry point where Java starts program execution.
  • Variable: A named storage location for a value.
  • Data type: The kind of data a variable stores.
  • Input: Data read into a program.
  • Output: Information printed or displayed by a program.

Basic Java program structure

public class HelloUser {
    public static void main(String[] args) {
        System.out.println("Hello, Java student!");
    }
}
  • public class HelloUser: the class name should match HelloUser.java.
  • main: the program starts here.
  • System.out.println(...): prints text and moves to a new line.

Input and output with Scanner

import java.util.Scanner;

public class IntroIO {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = input.nextLine();

        System.out.print("Enter your age: ");
        int age = input.nextInt();

        System.out.println("Welcome, " + name + ". Next year you will be " + (age + 1) + ".");

        input.close();
    }
}

Worked example

Problem

Write a program that reads a student's first name and two quiz scores, then prints the average score.

Pseudocode

  1. Start program
  2. Ask for first name
  3. Ask for quiz scores
  4. Compute average using (quiz1 + quiz2) / 2.0
  5. Print name and average
  6. End program

Java solution

import java.util.Scanner;

public class QuizAverage {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("First name: ");
        String firstName = in.nextLine();

        System.out.print("Quiz 1 score: ");
        double quiz1 = in.nextDouble();

        System.out.print("Quiz 2 score: ");
        double quiz2 = in.nextDouble();

        double average = (quiz1 + quiz2) / 2.0;

        System.out.printf("%s, your average is %.2f%n", firstName, average);

        in.close();
    }
}

Troubleshooting and common errors

  • class X is public, should be declared in a file named X.java: filename and public class name must match exactly.
  • cannot find symbol: check spelling and case of variable or method names.
  • InputMismatchException: text was entered when numeric input was expected.
  • No output appears: verify the latest saved file and expected class are running.

Knowledge check

Programming assignment

Student Info Summary Program

Write StudentSummary.java that reads student name, completed credits, and GPA; computes remaining credits to 60 total using Math.max(0, 60 - completed); and prints a clear summary with formatted GPA.

Required submission

  • StudentSummary.java
  • Short test log with at least three test cases, including one edge case

Testing guidance

  • Normal case, for example completed 24 and GPA 3.10
  • Near-completion case, for example completed 59
  • Boundary case, for example completed 60
  • Over-completion case, for example completed 72, and confirm remaining credits display as 0
